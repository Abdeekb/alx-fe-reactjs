# React Query Demo

This is a simple project demonstrating how to use React Query for fetching and managing data in a React application.

## Features

- Fetch data from JSONPlaceholder API using React Query
- Display a list of posts
- Handle loading, error, and success states
- Cache data with React Query for improved performance
